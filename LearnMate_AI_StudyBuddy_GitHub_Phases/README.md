# LearnMate (AI StudyBuddy) - AI Assistant for Smarter Learning and Study Support

This repository contains the complete project artifacts for **LearnMate / AI StudyBuddy**,
organized phase-wise as required for submission.

## Team
- **Team Head:** Ranganathan V G
- **Team Members:** Vikram C, Daniel Vasan S, Vinu N

## Project Summary
AI StudyBuddy is an AI-powered learning assistance platform built with Node.js, Express.js
and MongoDB, integrated with the Google Gemini AI API. It allows authenticated students to
upload study material and automatically generate summaries, flashcards, quizzes, and
personalized study plans.

## Important Note on Security
The `.env` file used during development (containing real database and API credentials) has
been **excluded** from this repository for security reasons, since this is a public repo.
A safe `.env.example` template is provided instead inside
`5. Project Development Phase/source_code/`. Before running the project, copy it to `.env`
and fill in your own credentials.
